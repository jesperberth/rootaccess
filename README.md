# rootaccess

The 3d first person shooter game in 90's style for the it crowd

## Game layout

The main caracter is walking around in the office with office furniture to avoid

He meets objects he needs to handle

- dumpsterfire
- hackers
- love you virus infected windows computer
- printers with paperjam

He has weapons to use and collect

- fire grenade
- shortgun
- antivirus McNorton

He can open doors

There should be different maps/levels

## Technical

Writen in javascript

Runs in AWS cloudfront, S3 bucket, deploys with github actions
